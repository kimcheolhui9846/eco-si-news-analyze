# eco-si-news-analyze

실시간 뉴스·재무·논문·실험·주식 차트 통합 분석 플랫폼.

수집한 자료의 출처를 명시하고, 뉴스·재무·연구·시장 데이터를 통합해 LLM으로 분석하여
핵심 요약, 동향 비교, 시나리오, 리스크 및 모니터링 지표를 제공하는 리서치 도구다.

## 진행 상태

| 단계 | 범위 | 상태 |
|---|---|---|
| Phase 1 | 코어 백엔드 — 인증·세션·비용방어·분석 엔진·테스트·문서 | 설계 완료, 구현 예정 |
| Phase 2 | 실 데이터 커넥터 5종 + `/api/research` 오케스트레이션 | 미착수 |
| Phase 3 | React 프론트엔드 | 미착수 |

설계 문서: [`docs/superpowers/specs/2026-09-02-phase1-core-backend-design.md`](docs/superpowers/specs/2026-09-02-phase1-core-backend-design.md)

## 면책

본 프로젝트가 생성하는 분석은 제공된 자료를 기반으로 한 정보 제공 목적의 분석이며,
특정 금융상품의 매수·매도 또는 투자 수익을 보장하는 투자 권유가 아니다.
